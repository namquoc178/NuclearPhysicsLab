# NuclearPhysicsLab

Website mô phỏng trực tuyến Vật lí hạt nhân dành cho học sinh THPT.

## GitHub Pages

Repo này là website tĩnh. Sau khi đẩy toàn bộ nội dung thư mục này lên nhánh `main`:

1. Vào **Settings → Pages**.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh **main** và thư mục **/(root)**.
4. Lưu lại và chờ GitHub Pages xuất bản.

Trang chủ là `index.html`; toàn bộ đường dẫn nội bộ dùng đường dẫn tương đối nên phù hợp với GitHub Pages theo dạng project site.
